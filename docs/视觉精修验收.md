# P5X 视觉精修本地验收

本轮实现底版、光效、背景和纹理；不包含立绘调整，也不代表 AstrBot 消息发送已验收。未推送 GitHub。

## 已实现

- 十连标准画布1920×1080，保留4px槽位间距及现有宽度、错落布局。
- 顶部和左侧不描黑框；右侧保留黑衬底。低星底部由三角衬底直接形成，取消横穿三角的重复底线，两下角延伸18px。
- 背景拼贴等比裁切；蓝色切线独立归一化绘制，不再随背景裁切移动，最终恢复蓝线，避免被光效覆盖。
- 高星顶底柔光先合成，后由所有底版遮挡；内部特效逐张裁切，最后恢复可见黑色分隔。低星不绘制光效，不被邻卡染色。
- 4★金色，两处短亮边、一个小星芒；5★紫白色，三处短亮边、一至两个不同大小星芒。短亮边不超过色带高度8%，碎光聚集在亮边附近。参数由物品ID和展示槽位稳定生成。
- 保留60项人格面具属性与来源；武器独立按星级配色，缺属性使用固定默认色。菱形纹理随输出缩放，低星无额外白色提亮。
- 缩小十连从标准画布等比缩放，非16:9目标尺寸补边，不直接拉伸或截断色带。
- 单抽修正光效坐标二次缩放，仅修改特效坐标，不修改立绘定位。
