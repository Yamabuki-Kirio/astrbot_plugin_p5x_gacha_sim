# 底版与光效验收

最新一轮固定样本、测试结果与限制见 [视觉精修验收](视觉精修验收.md)。下文保留此前阶段记录。

本轮只验收非立绘部分。用户已暂停立绘调整，现有素材及定位不能视为通过验收。

## 当前可检查

- 十条向左下倾斜的色带，上下边缘错落；设计坐标下相邻槽位间距由 8px 收紧至 4px。
- 左侧、顶部无黑边，颜色直达边缘；仅右侧、底部有黑色衬底。后方黑线不穿过前方底版。
- 色带内细菱形纹理及纵向明暗变化。
- 低星三角黑衬底左右下角均下移18px。
- 2★、3★无辉光、无边缘碎光；4★金色；5★紫白色。
- 高星采用断续边缘亮线、碎片及局部星芒，不在底部排列大星形徽章。
- 高星短亮边与碎光限制在色带内；新增顶底背景光束先合成，再由所有底版与黑衬底遮挡。黑色分隔最后按可见轮廓合成，不染亮低星或吞掉黑边。
- 当前十连为1920×1080；布局重新排布，背景等比覆盖裁切，不拉伸。
- 60个人格面具属性已从BWIKI图鉴字段同步，包含来源；卡池名单和稀有度未改。
- 单抽、十连均不绘制奖励条、数量、底部标识及人工蓝色身影。
- 当前背景保留已有黑灰拼贴及上下蓝色切线，不宣称已逐像素还原参考。

## 待做实现规格（按后续顺序）

### 1. 底版几何最终校准

- 以当前 4px 间距为起点，对照参考校准十条色带的宽度、顶底高度和整体占屏范围。
- 保留左/上无黑边、右/下黑衬底；禁止恢复完整四边相框。
- 验收普通十连、多高星、全低星、全武器四组；不得出现双黑线、穿透黑角或局部吞边。

### 2. 高星光效精修

- 2★/3★不绘制任何辉光、碎光或星芒，不接受相邻高星光效染色。
- 4★金色、5★紫白色；区分强弱，不采用所有高星完全相同的闪光节奏。
- 亮线不再作为均匀长线装饰，调整为参考中的局部高亮与短段碎光；控制数量和面积。
- 保持黑色分隔可辨。若以后增加卡外光束，必须遮掉低星底版与黑色衬底区域，不能直接全图叠加。
- 验收四种星级单独出图及相邻混合出图。

### 3. 背景与画布比例

- 已改为1920×1080，后续仅按视觉验收微调占屏位置，不对最终图像拉伸。
- 校准黑灰拼贴的缩放、对比度，上下蓝线的斜率、位置、折角及粗细。
- 不加入资源栏、返回、分享、账号信息或其他外围 UI。

### 4. 属性色与纹理

- 仅对可核实的属性填写配色映射；缺属性继续使用明确的默认色，不随机配色。
- 对照参考调整菱形大小、透明度与渐变；避免细纹消失或纹理抢过主体。
- 不以当前已导入人格面具清单证明实际卡池名单正确。

### 5. 立绘（暂缓，不在当前执行范围）

- 等用户确认素材方案后，再处理质量、透明背景、角色主体定位和裁切。
- 角色原画自带的蓝色身影保留，不绘制替代蓝影。
- 需要全素材定位总览及代表性十连验收，不能仅凭自动居中宣布全部适配。
