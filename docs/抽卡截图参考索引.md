## 对后续实现的约束

1. 主基准仍是用户提供的图；其他版本只用于证明通用视觉关系。
2. 常见构图有16:9及更宽比例。1920×1080是插件的输出选择，不是所有游戏截图唯一正确的比例。
3. 高星亮边、星芒和顶底柔光是不同图层；不能把通用效果画成长灯管，也不能把原画背后的身影当作光效生成。
4. 低星没有高星辉光；底部是斜切黑色楔形，不是规整四边卡框。
5. 角色与武器配色分别验证；不依据截图数量推断实际卡池或抽卡概率。
6. 参考图里的奖励、角色标识、NEW、资源栏、分享、ID、继续十连等UI仍不在本插件当前还原范围内。
